## 现场现象分析

已确认红外极性：

```text
白线/白底：DO = 0V
黑线：DO = 3.3V
```

因此当前代码：

```c
#define LINE_BLACK_IS_HIGH 1
```

是正确的，不需要改极性。

如果仍然只有上电 1 声，可能原因是：

1. 上电初始采样时某一路红外被误读为高电平，程序直接进入 `PHASE_LINE_RUN`，没有进入桥接。
2. 进入桥接或重捕线的蜂鸣提示太快/被电机声音盖住，现场难以判断。
3. 烧录的不是最新版本。

V27 的目标是让状态切换变得肉眼可见。

## 新增行为

每次关键状态切换时，车会强制停车约 2 秒，再继续运行。

```c
#define STATE_SWITCH_HOLD_FRAMES 100U
```

约等于 100 个 20ms 舵机周期，即约 2 秒。

## 状态提示

```text
上电 1 声：程序启动
停 2 秒 + 2 声：程序进入 A 点无线桥接
停 2 秒 + 4 声：程序上电时直接认为已经有线，进入普通循迹
停 2 秒 + 3 声：桥接过程中任意红外看到黑线，切入普通循迹
长响：桥接超时仍未看到黑线
```

## 判断规则

### 情况 A：白底启动，听到 2 声并停 2 秒

说明：

```text
白底被正确判断为无线起步
g_phase = PHASE_START_GAP_BRIDGE
```

接下来如果弯道处没有 3 声，说明实际运行时红外阵列没有压到黑线，或行进中红外/接线异常。

### 情况 B：白底启动，听到 4 声并停 2 秒

说明：

```text
程序上电时误判已经有线
```

需要查：

- 是否某一路红外在白底仍为高电平。
- 是否有 DO 线松动/悬空。
- 是否车底某个传感器刚好压到黑色结构、阴影或胶带。

### 情况 C：弯道处听到 3 声并停 2 秒，但继续后仍冲出去

说明：

```text
重捕切换成功
问题转移到普通循迹弯道参数/速度
```

下一步应调普通循迹或降低切入弯道速度。

### 情况 D：弯道处始终没有 3 声

说明：

```text
桥接阶段代码没有读到任何黑线
```

优先查车实际路径是否让传感器压到黑线，而不是继续改切换逻辑。

## 新增 Watch 变量

```c
g_state_switch_reason
g_state_switch_hold_event_count
g_state_switch_hold_frames_total
```

含义：

```text
g_state_switch_reason = 1：进入桥接
g_state_switch_reason = 2：桥接重捕线进入循迹
g_state_switch_reason = 3：上电直接进入循迹
```

## 当前有效路径

```text
白底启动：
PHASE_START_GAP_BRIDGE -> 看到任意黑线 -> PHASE_LINE_RUN

黑线启动：
PHASE_LINE_RUN
```

`START_GAP_TEST_ONLY=1U` 仍保持开启，第一轮只用于定位 A 点桥接和重捕线。
