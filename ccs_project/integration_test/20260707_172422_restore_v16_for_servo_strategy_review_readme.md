## 回退原因

V17 将水平舵机左偏范围扩大到：

```c
#define SERVO_X_MAX_US              3050U
#define COURSE_LEFT_TARGET_US       3000U
```

但现场重新判断后，存在一种更合理的可能：舵机/控制方式本身只能通过位置 PWM 稳定控制约 180 度，机械云台虽然手动可以无限旋转，但程序未必能做绝对 270 度位置控制。

因此当前先回退到 V16 安全边界：

```c
#define SERVO_X_MIN_US              350U
#define SERVO_X_MAX_US              2650U
#define COURSE_LEFT_TARGET_US       2550U
#define COURSE_PREAIM_RETURN_STEP_US 140
```

## 结论

普通三线舵机的位置 PWM 是“绝对位置命令”，不是“相对旋转命令”。如果没有编码器、角度传感器或可控复位机构，不能可靠实现“先转到 180 度，软件重置，再继续相对转 90 度”。

若水平舵机是连续旋转舵机，则 PWM 通常控制速度和方向，而不是角度。这种情况下可以通过定时估算转 90 度，但没有角度反馈，误差会随电压、负载、摩擦累积，不适合精确打靶。

## 当前建议

先不要再扩大 PWM 范围。下一步应单独写一个水平舵机识别/扫角测试程序，判断它到底是：

1. 位置舵机：不同脉宽对应固定角度，到位后保持。
2. 连续旋转舵机：偏离中位后一直转，脉宽决定速度。
3. 机械结构打滑/云台可手动无限转，但舵机输出轴实际不是无限位置可控。

确认类型后，再决定是继续用绝对角度控制，还是改为“定时扫描 + OpenMV 看到目标后锁定”的策略。
