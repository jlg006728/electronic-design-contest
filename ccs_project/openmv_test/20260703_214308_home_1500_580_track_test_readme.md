- 红色目标在画面右侧：水平舵机应向右追。
- 红色目标在画面左侧：水平舵机应向左追。
- 红色目标在画面上方：俯仰舵机应向上追。
- 红色目标在画面下方：俯仰舵机应向下追。

如果某一轴方向反，只改 MSPM0：

- 左右反：改 `AIM_X_PULSE_SIGN`
- 上下反：改 `AIM_Y_PULSE_SIGN`

如果图像本身还倒，不要先改舵机方向，先改 OpenMV 的 `CAMERA_HMIRROR/CAMERA_VFLIP`。
