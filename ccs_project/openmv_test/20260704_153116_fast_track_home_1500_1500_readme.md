## 判断

- `g_aim_state = 2`：正在追踪。
- `g_aim_state = 3`：目标在中心死区，舵机不应继续动。
- `g_aim_state = 6`：目标太小，被拒收。
- `g_aim_state = 7`：目标刚出现，等待连续帧确认。

如果目标在右边却越追越偏，改 `AIM_X_PULSE_SIGN`。如果上下越追越偏，改 `AIM_Y_PULSE_SIGN`。
