## 接线

所有模块必须共地，必须断电接线，禁止带电插拔。

### 左右轮编码器

| 编码器信号 | MSPM0G3507 | 程序用途 |
|---|---|---|
| 左轮A | PB12 / PINCM29 | A相上升沿计数 |
| 左轮B | PB13 / PINCM30 | 读取方向 |
| 右轮A | PB14 / PINCM31 | A相上升沿计数 |
| 右轮B | PB15 / PINCM32 | 读取方向 |
| GND | 公共GND | 必须与主控、TB6612共地 |

编码器A/B输入到MSPM0端的高电平不得超过3.3V；供电方式沿用已经验证的编码器额定供电，不确定输出电平时先用万用表/示波器确认，禁止把5V推挽信号直接送入PB12-PB15。

V94只对左右A相上升沿触发中断，B相仅判断方向，以降低中断频率。已知正确前进方向应满足：`g_encoder_left_count`持续减小、`g_encoder_right_count`持续增大。任一方向相反、任一车轮连续500 ms没有新增有效脉冲、单轮累计里程达到另一轮4倍或端点超过硬停止距离，都会停车；双轮同时500 ms不动记为整车无运动故障。

## 固定路线

访问顺序为：

`药房 → 1 → 2 → 3 → 4 → 7 → 5 → 6 → 8 → 药房`

关键动作如下：

1. 药房向北到近端路口，左转进入1号病房；停2秒，左向原地180°。
2. 回到近端路口后直行到2号病房；停2秒，原地180°。
3. 回到近端路口，右转向北；到中部路口左转进入3号病房；停2秒并掉头。
4. 穿过中部路口直行到4号病房；停2秒并掉头；回中部路口右转向北。
5. 到远端中心路口左转向西；到远端左路口左转向南进入7号病房；停2秒并掉头。
6. 穿过远端左路口直行到5号病房；停2秒并掉头；回远端左路口左转向东。
7. 穿过远端中心路口到远端右路口，右转向南进入6号病房；停2秒并掉头。
8. 穿过远端右路口直行到8号病房；停2秒并掉头；回远端右路口右转向西。
9. 回远端中心路口左转向南，依次穿过中部、近端路口，回药房端点停车。

完整53步动作表位于 `medicine_route.h`。路线会访问所有8个物理门口，因此本阶段即使3-8数字纸张随机，也不依赖数字识别。

## 上电操作

1. 架空驱动轮完成第一次测试；确认OpenMV断开、灰度OUT已分压、MPU供电为3.3V、PB12-PB15编码器已连接且输入不超过3.3V。
2. 将车头对准药房主线方向，让灰度板位于主线起点前方的白底上，车轮不得触碰地面障碍。
3. 上电后保持整车和MPU完全静止。程序先检测WHO_AM_I并采500个样本做Z轴零偏标定，再采50帧白底建立灰度基线。
4. 标定完成后LED保持约2秒准备时间，随后小车自动启动。当前版本没有启动按键，人员必须提前离开轮子和赛道。
5. 发生任何故障时电机停车，LED约100 ms亮/100 ms灭；完整返回药房后LED约80 ms亮/320 ms灭。

启动通过值：`g_mpu_state=3`、`g_mpu_link_ok=1`、`g_mpu_who_am_i=0x68或0x70`、`g_calibration_sample_count=500`、`g_gray_white_baseline_mask=0xFF`（当前白底高电平板）。

## 分阶段验收

### 0. 新MPU独立验收

先运行既有独立程序 `20260722_mspm0_new_mpu_validation.c`。静止60秒漂移目标不超过5°，左右手动旋转时角速度符号必须相反，连续I2C失败为0。未通过时不要运行V94电机转向。

### 0.5 编码器独立验收与标定

先用既有 `encoder_motor_calibration.c` 或架空V94核对方向：左轮前进为负计数、右轮前进为正计数，两侧A相边沿都必须持续增加。既有独立程序使用A相双边沿，只适合核对方向；若用它测距离，所得edges/cm必须再除以2才能填入V94的上升沿参数。随后按V94的计数方式落地直行实测50 cm，记录起止计数并计算：

`edges_per_cm = (abs(左轮差值) + abs(右轮差值)) / (2 × 50)`

三次50.0 cm净计数实测分别得到`664.86`、`667.62`、`660.96 edges/cm`，平均`664.48 edges/cm`；V94使用最近整数`ENCODER_RISING_EDGES_PER_CM=664`。左右轮三次平均差约0.22%，三次CV约0.5%，方向与重复性均通过。

按实测系数，Watch中的临时端点接受窗口为：病房`13280～46480 edges`，最终药房`13280～66400 edges`。为允许连续8帧确认期间低速前移，硬停止上限另留5 cm缓冲，分别为`49800`和`69720 edges`；第一次全灭必须已经位于接受窗口内，不能在同一次丢线过程中“跑进窗口”后再被承认。每进入一个新的follow动作，`g_route_left_start_count/g_route_right_start_count`和局部里程都会重新建立，不是全程累计距离。

### 1. 架空电机方向

只观察第一次左转：A侧轮应反转、B侧轮应前进；右转相反。`g_turn_motion=2/3`表示左转，`4/5`表示右转。若物理方向与此不一致，先检查A/B电机接线。

### 2. 单路口90°

只搭建药房到近端路口及1号支线。要求：

- `g_route_action_index` 从0进入1，再进入2；
- 宽路口连续2帧才计数，`g_junction_event_count=1`；
- 转向前先低速前移，使轮轴中心到路口中心，再静止约100 ms；
- 左转结束时 `abs(g_turn_error_mdeg) <= 2500`，且不会继续旋转到超时；
- 若向左旋转时 `g_turn_yaw_mdeg`持续为负，立即停车并把 `MPU_LEFT_POSITIVE_SIGN` 从1改为-1，不能增大PWM硬顶。

### 3. 单病房

搭建药房、近端路口和1号门口。端点不再仅靠断线判断，必须依次满足：本follow动作平均前进已进入临时20～70 cm接受窗口、丢线前连续5帧位于中央、随后连续8帧全灭；若第一次全灭时不足20 cm，即使继续在全白区域跑到20 cm也不能到站，必须重新捕获红线后建立新候选。超过75 cm硬上限仍未识别则按“错过端点”停车。病房动作索引3保持 `2.00 s ± 0.05 s`，随后索引4执行180°掉头。

Watch要求：第一次全灭前`g_route_endpoint_distance_ready=1`；全灭后锁存的`g_route_endpoint_entry_distance_ready=1`、`g_route_endpoint_entry_centered=1`，随后`g_route_lost_frames`才允许增长；`g_route_progress_fault=0`；停留后`g_ward_stop_count=1`、`g_visited_ward_mask=0x01`。

进入动作索引4后还应满足`g_ward_bias_update_count=1`、上一病房的`g_ward_bias_sample_count>=50`。程序只从停留第500 ms开始接收绝对角速度不超过3000 mdps的样本，并在2秒停留结束、下一动作同步前一次性更新Z轴零偏；若计数没有增加，说明停留时车体仍在振动或MPU数据不稳定。

### 4. 近端与中部

先完成1、2，再加入3、4。确认“返回路口后直行去对面病房”不会把同一路口重复计数；每个新follow动作必须经过至少30个正常红线帧并连续5帧稳定后才重新布防。

### 5. 远端左右支路

分别测试7/5和6/8。重点观察穿过中间路口时宽线只会直行，不会被当作病房端点。

## 单变量调参顺序

1. 左转角度符号反：只改 `MPU_LEFT_POSITIVE_SIGN`。
2. 90°转弯中心过早/过晚：只改 `JUNCTION_CENTER_FORWARD_MS`，当前220 ms。
3. 接近目标仍冲过：先降低 `TURN_SLOW_PWM` 或扩大 `TURN_SLOW_ZONE_MDEG`，不要先放大容差。
4. 编码器距离不准：先重新实测50 cm并修改 `ENCODER_RISING_EDGES_PER_CM`，禁止先放宽端点窗口掩盖计数错误。
5. 路口重复计数：增加 `min_travel_frames` 或 `rearm_normal_frames`。
6. 病房完全不停：依次检查编码器方向、`g_route_average_forward_edges`、距离窗口、丢线前5帧是否居中以及红线是否确实终止。
7. 病房提前误停：保存当前动作的3次实际门口里程，再单独修改 `medicine_route.h` 中该 `MEDICINE_ROUTE_ENDPOINT(...)` 行；不能把九段一起改，也不能只增加全灭帧数。
8. 直线摆动：观察归一化 `g_gray_line_x*`，再单独调循迹速度/增益，不要根据物理板载灯判断红线位置。

每次只改一个参数并至少重复3次，记录成功率、最终角度误差和触发动作索引。
